Prompts used for P2, copied word for word, in order.

## P2-1

```
Read skills/prolog-dev/SKILL.md and follow it. Do not run any git commands (I will commit myself). Touch only the file(s) I name below. Do not add any initialization directive and never call halt/0. Do exactly the one unit of work described below and nothing more.

File: code/16_q2.pl. Write only eval_ok(+Op, +A, +B, -V) where Op is one of +, -, *, / and A, B are integers (possibly negative). V is the integer result of A Op B. For / it succeeds only when B =\= 0 and A mod B =:= 0, and then V is A // B (exact division only; never produce a float). Add a one-line declarative comment above it. Then run goals showing: eval_ok(/, 8, 4, V) gives 2, eval_ok(/, 5, 2, V) fails, eval_ok(/, 4, 0, V) fails, eval_ok(-, 3, 5, V) gives -2, eval_ok(/, -6, 3, V) gives -2. Show me the output.
```

## P2-2

```
Read skills/prolog-dev/SKILL.md and follow it. Do not run any git commands (I will commit myself). Touch only the file(s) I name below. Do not add any initialization directive and never call halt/0. Do exactly the one unit of work described below and nothing more.

File: code/16_q2.pl. Add only expr_tree(+List, -Tree, -Value). List is a list of non-negative integers. Then run: findall(Tr-V, expr_tree([2,4], Tr, V), L) and show it (I expect 3 results: 6, -2, 8) and findall(V, expr_tree([1,2,3],_,V), Vs) with its length.
```
